# LPH-web

Website frontend for LPH STAI Tanbihul Ghofilin.

## Quick start

1. Install dependencies:

```bash
npm install
```

2. Create a development env file in `apps/web`:

```bash
cd apps/web
echo VITE_WHATSAPP_ADMIN=628xxxxxxxxxxx > .env
```

3. Run the dev server from repository root:

```bash
cd "d:\LPH web\horizons-export-5a638aa5-b923-4e59-8a4e-0dd6647b2c24"
npm run dev
```

Open http://localhost:3000

## WhatsApp Admin button

Configure the admin number by setting `VITE_WHATSAPP_ADMIN` in `apps/web/.env`.
